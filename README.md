# 📊 Sales & Profit Analysis Dashboard — Power BI

## 📌 Project Overview

This project is an interactive **Sales & Profit Analysis Dashboard** developed using **Microsoft Power BI**. The dashboard transforms raw sales data into meaningful business insights through interactive visualizations, KPIs, and trend analysis.

The objective of this project is to analyze overall business performance, identify profitable areas, understand monthly trends, and provide a clear view of key sales and financial metrics.

## 🎯 Business Objectives

- Analyze overall sales and quantity performance
- Track profit trends across different months
- Evaluate Average Order Value (AOV)
- Identify high-performing product categories
- Analyze customer payment methods
- Compare sales and profitability across different segments
- Identify patterns that can support better business decisions

## 📊 Key KPIs

The dashboard provides an overview of important business metrics, including:

- **Total Quantity Sold**
- **Average Order Value (AOV)**
- **Total Profit**
- **Monthly Profit Trends**
- **Category-wise Performance**
- **Payment Method Distribution**

## 🛠️ Tools & Technologies

- **Microsoft Power BI**
- **Power Query** — Data cleaning and transformation
- **DAX** — Calculated measures and business metrics
- **Microsoft Excel** — Data source and preparation
- **Data Visualization** — Interactive charts, KPIs, and filters

## 🔍 Key Analysis

The dashboard provides interactive analysis of:

### 📈 Profitability Trends

Analyze how profit changes over time and identify months with stronger or weaker performance.

### 🛒 Sales Performance

Understand sales volume and order value using key performance indicators.

### 📦 Product Analysis

Compare different product categories to identify high-performing and low-performing segments.

### 💳 Payment Analysis

Understand customer payment preferences and their contribution to overall transactions.

## 💡 Business Value

The dashboard demonstrates how raw transactional data can be transformed into an interactive business intelligence solution. It enables users to quickly identify performance trends, compare business segments, and derive actionable insights from data.
